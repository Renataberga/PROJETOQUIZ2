# Projeto orientado a objeto

>[!NOTE]
>O **Projeto orientado a objeto** é composto pelas documentação do projeto descrito em UML. Deve incluir um Diagrama de Classes do sistema projetado, e pelo menos um diagrama de interação de um dos casos de uso. Outros diagramas podem ser apresentados, caso julgue necessário.

## O diagrama representa três classes principais:

### Pergunta:
Guarda o texto da pergunta, as alternativas e a resposta correta. Possui um método que verifica se a resposta escolhida pelo jogador está certa.

### Jogador:
Armazena o nome do jogador e sua pontuação. Tem um método para somar pontos quando o jogador acerta uma questão.

### Quiz:
É o controlador do jogo. Possui uma lista de perguntas e um jogador. Controla o início do jogo, a exibição de perguntas, a verificação das respostas e a exibição do resultado final.
